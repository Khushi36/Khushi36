## 🚀 Featured Projects

### 🛡️ [Property Guardian AI](https://github.com/Khushi36/Property-Guardian-Ai)
A multi-database property fraud detection and ownership analysis platform.
- Graph RAG query engine combining ChromaDB (semantic search), PostgreSQL (structured lookup) and Neo4j (graph traversal), so an LLM can answer natural-language questions about property records
- 4-stage PDF ingestion pipeline (PyPDF → pdfplumber → Tesseract OCR → LLM fallback) with RapidFuzz entity matching for deduplication
- Fraud detection using SQL `LAG()` window functions to find broken ownership chains and double-selling
- JWT auth with CAPTCHA and email OTP, Redis rate limiting, audited read-only SQL console
- Dockerised with 4 services via Docker Compose

`FastAPI` `Streamlit` `PostgreSQL` `Neo4j` `ChromaDB` `Redis` `Docker` `OpenRouter`

### 📘 Word Sense Disambiguation using Modified Lesk
Resolves word-sense ambiguity in English and Hindi sentences using a modified Lesk algorithm with WordNet and POS tagging.

`Python` `WordNet` `NLTK`

### 🔮 [Crystal Ball](https://github.com/Khushi36/Crystal_Ball)
